# 플레이테스트 반영 c — 봇끼리 판 전후 통계 (봇 · 손맛)

같은 도구(`scripts/bot-stats.ts` — c 기반 `6c506bb`과 생존자 갈래에서 고친 판)로 같은 시드 300판(1~300, `room` 흐름 = 실제 방 + 실제 BotDriver)을 b 최종 코드(`4570685`, git worktree를 `--repo`로)와 c 최종 코드(`c131222`)에서 쟀다. 사람 흉내 괴물(novice · mid) 대 생존자 봇 셋도 같은 시드로 견줬다. c에서는 봇 두뇌가 양쪽 다 바뀌었다 — 생존자(서성이기 · 돌아가기 · 미끼 · 반응 지연 · 역할 단서 없애기 · 판 시간 시계)와 괴물(돌진 연계 · 거리 좁히기 돌진 · 포효 핑 · 점령 알림 기억 · 둘레 돌기 · 놓친 뒤 수색 · 동점 결정성). 두 갈래를 합친 뒤 손잡이 셋(괴물 손 · 생존자 조심 · 감옥 감시)으로 맞췄다(5절). 판 안 규칙 · `balance.json`은 그대로다. 결정 · 이유는 `DECISIONS.md` 16절 'c:' 행.

결과 JSON 몇 개는 머리의 `gitHead`가 `620f4c7`이다 — 잰 때의 HEAD이고, 작업 트리의 두뇌 코드는 `c131222`와 같다(조심 가중치만 커밋 전).

## 도구 (c에서 더한 것)

| 무엇 | 뜻 |
|---|---|
| `--monster novice\|mid` | 괴물 자리를 사람 흉내 대역으로 바꾼다(`tests/helpers/humanMonster.ts`, `c-bots.md` 2.2절 정의 — novice '처음 해 보는 사람', mid '조금 해 본 사람'). `--repo`와 무관하게 이 리포의 대역을 써 같은 잣대로 전후를 잰다. 옛 코드 `da628d7`에서 원래 조사 수치(novice 명중률 26.7% · 판당 수감 1.73)에 가깝게 맞췄다: `reachMargin` 0.3 → 25.6% · 1.83 |
| `--aliases seeded`(기본) · `--alias-salt N` | 괴물에게 가는 생존자 임시 ID를 판마다 (seed, 소금)으로 다시 시작하는 시드 난수로 만든다 — 이 프로세스의 `crypto.getRandomValues`만 바꿔치기한다(도구 안에서만, 제품 코드는 그대로 암호 난수). 그래서 두뇌가 임시 ID에 기대는 b 이전 코드로 잰 '전' 값도 실행마다 같다. b 보고(`b-bot-stats.md`)의 '같은 시드도 승패 ±1판 흔들림'이 없어 전후 비교를 믿을 수 있다 |
| `--diff A B` | 두 결과 JSON에서 판 지문(fingerprint)이 다른 seed를 적는다. 소금만 바꿔 돌린 두 결과를 견주면 두뇌가 임시 ID에 기대는지 본다(4절) |
| 새 수치 | 거점별 점령 시작~완료 · 그중 점령되던 초, 수감 분포(중앙값 · 0번인 판 · 2번 이상인 판), 생존자 봇 할 일 종류 전환 · 1초 안에 되돌아간 전환, 쫓기지 않을 때 1초 넘게 선 구간 수 · 가장 긴 구간 |

```bash
npx tsx scripts/bot-stats.ts --matches 300 --seed 1 --repo <4570685 worktree> --quiet --out before.json
npx tsx scripts/bot-stats.ts --matches 300 --seed 1 --quiet --out after.json
npx tsx scripts/bot-stats.ts --compare before.json after.json
# 사람 흉내 괴물: 위 두 줄에 --monster novice (또는 mid)를 붙여 같은 방법으로
npx tsx scripts/bot-stats.ts --matches 300 --seed 1 --monster novice --quiet --out after-novice.json
# 결정성: 임시 ID 소금만 바꿔 다시 재고 지문 비교 (--flow sim 도 같은 방법)
npx tsx scripts/bot-stats.ts --matches 300 --seed 1 --alias-salt 7 --quiet --out after-s7.json
npx tsx scripts/bot-stats.ts --diff after.json after-s7.json
```

읽는 법: '마지막 점령' = 탈출구를 켜는 데 한 곳만 더 필요하던 구간(b와 같다). '생존자 봇 서 있던 시간'은 b와 같은 정의라 `room` 흐름에서는 시작 카운트다운 3초가 늘 들어 있다(카운트다운 동안 봇은 입력을 보내지 않는다). 새 수치 '1초 넘게 선 구간'은 카운트다운 틱을 뺀다. '괴물 봇 서 있던 시간'은 시작 5초 정지 · 기절을 뺀다. '할 일 종류 전환'은 두뇌의 진단용 `debugState()`(결정에 쓰지 않는다)를 읽어 옛 두뇌에서는 셀 수 없다('–'). 같은 코드도 300판 시드 묶음에 따라 괴물 승률이 ±4%p 흔들린다(3절) — 승률은 1,200판 값으로 읽는다.

## 4. 결정성 (같은 시드 봇 판이 드물게 다르던 것)

**원인**: 구조로 함께 풀려난 두 생존자가 정확히 같은 좌표에 나타나면 괴물 두뇌 `pickTarget`의 위치 동점이 괴물 스냅샷의 생존자 배열 순서(= 암호 난수 임시 ID 순)로 갈렸다. b 최종을 임시 ID 소금만 바꿔 `sim` 흐름 300판을 돌리면 시드 36 · 114 · 183이 다르다(시드 36: 540틱 (24.594, 18.493)에 둘). `room` 흐름은 5번 재도 300/300 같았다 — 드문 일이다. 생존자 두뇌는 임시 ID를 받지 않는다(생존자 스냅샷에는 괴물용 임시 ID가 없다).

**고침**: 표적 동점은 위치 → 속도 → 처음 본 틱으로 가르고, 그래도 같으면 둘을 묶어 쫓는다(`chaseIds` — 누구인지 고르지 않는다). 포효 핑 순서도 좌표로 동점을 가른다. 임시 ID 값 · 배열 순서에 기대지 않는다.

**시험**: `tests/bots/monster-brain.test.ts` 「표적 동점: 같은 자리 · 같은 속도 · 같이 처음 본 생존자 둘은 임시 ID 값 · 배열 순서와 무관하게 같은 결정 …」(손으로 만든 스냅샷)과 「같은 시드는 임시 ID 값 · ID 크기 순서 · 배열 순서가 달라도 같은 판 …」(봇끼리 판 — 동점은 시험이 직접 만든다. b 최종 두뇌는 시드 36에서 실패).

## 7. 거점 C 분석 (요약)

검토 수리 전 c 봇(`e94dd76`과 같은 두뇌, seed 1~600 — 괴물 승률 34.5%)에서 거점별 열린 동안 · 탈출한 문을 읽기 전용 계측 사본으로 다시 쟀다(판 지문 600/600 같음). 결론은 최종 1,200판 수치와 같은 방향이다.

- **맵 · 수치는 바꾸지 않는다.** 사람 판에서 'C 마지막 → 북문'이 괴물에게 너무 불리하다고 확인될 때만 볼 후보: ① 북쪽 통로(x 20–27, y 3–5)에 2×2 기둥 — C → 북문 길이 1~2타일 늘고 직선 시야가 끊긴다. 북문 옆 매복 자리가 생기고 맵 규칙(통로 폭 2) · 데칼 · 골든 해시 · 프로토콜 관문을 다시 확인해야 한다. ② 감옥 쪽 기둥 (23–24, 10–11)을 옮기기 — '거점 지키기 = 감옥 지키기'가 생기고 지금 봇에서는 C가 이미 가장 어려워 방향이 반대(비추천). ③ 거점 반경 · 탈출구 여는 시간 — 세 거점 · 두 문 공통 키라 C만 바꾸려면 거점별 값을 새로 만들어야 한다(비추천). 사람 확인은 HUMAN_CHECKS의 C 자리 · 'C 마지막 → 북문' 항목.

## 요약

- **괴물 승률 45.3% → 35.0%**(seed 1~300), 1,200판 **32.1%**로 목표 30~40% 안이다. 같은 코드도 300판 묶음에 따라 27.3~35.0%로 흔들린다. 두 갈래를 합친 직후 65.2%였던 것을 괴물 손 · 생존자 조심 · 감옥 감시 세 손잡이로 내렸다(5절).
- **판 길이는 그대로 2분대**다(중앙 2:10 → 2:18, 1,200판 2:19, 7~10분 판 0). 봇만으로는 닿지 않는다 — 밸런스 후보(8절, 1위 수감 한도 8 · 점령 160초)는 보고만 하고 `balance.json`은 바꾸지 않았다.
- **서 있지 않는다**: 생존자 봇 서 있던 시간 5.9 → 3.4초(그중 3초는 시작 카운트다운), 쫓기지 않을 때 1초 넘게 선 구간 0 · 가장 긴 0.9초. 괴물 봇 19.8 → 6.0초.
- **사람 흉내 괴물**: novice 판당 수감 2.39 → 2.80(중앙 2 → 3, 0번인 판 18 → 8, 600판 2.70), 명중률 39.5 → 85.1% — 생존자 봇이 준비 동작에 사람처럼 늦게 반응한다. mid 괴물 승률 29.7 → 33.3%(600판 32.0%)로 괴물 봇과 비슷한 세기다.
- **괴물 봇 명중률 82.5 → 63.5%**(mid 대역 69.6%보다 낮게). 대신 덜 서 있고 더 자주 마주쳐 판당 수감 4.39 → 4.71. 3명 동시 수감으로 끝난 판 29 → 9.
- **거점 C는 가장 덜 끝난다**(1,200판 A 873 · B 707 · C 503). 'C 마지막 → 북문' 지름길 이득은 1~3초, 판 결과로 바뀔 몫은 1%p 안팎이 상한 — 맵은 그대로(7절).
- **결정성**: 같은 시드 판은 임시 ID 값 · 순서가 달라도 같다(c 최종 `room` · `sim` 각 300/300). 도구가 판마다 시드 임시 ID를 써 b 이전 코드의 '전' 값도 실행마다 같다.
