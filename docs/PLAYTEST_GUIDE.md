# DECOY 플레이테스트 가이드 (팀원용)

개발은 차형창이 하고, 김도유 · 윤나희는 테스트와 밸런스를 맡는다. 테스트 결과가 남아야 팀원 기여도 기록으로 남는다.

## 역할

| 팀원 | 맡는 일 | 남기는 기록 |
|---|---|---|
| 김도유 (팀장) | 플레이테스트 운영, 버그 수집, 외부 테스트 섭외, 발표 | GitHub Issues 버그 리포트, 테스트 기록 |
| 윤나희 | 밸런스와 맵 피드백, 괴물 역할 집중 테스트 | `config/balance.json` 수치 조정 PR, 피드백 기록 |
| 차형창 | 개발, 수정 반영 | 커밋 |

## 테스트 한 번 하는 법

1. 차형창이 보낸 링크로 접속 (`.../?room=ABCD`)
2. 역할을 고르고 시작. **괴물 역할은 판마다 돌아가며** 맡는다
3. 판이 끝나면 아래 기록 양식을 채운다
4. 버그는 GitHub Issues에 올린다 (제목: `[버그] 무엇이 어떻게`, 본문: 재현 방법, 스크린샷)

## 기록 양식 (판마다)

```
날짜 / 판 번호:
괴물:            러너:           가드:           스카우트:
결과: (생존자 승리 n명 탈출 / 괴물 승리 / 시간 초과)
판 길이: 약 __분
가장 재밌던 순간:
답답했던 순간:
괴물이 너무 강했나 / 약했나 / 적당했나:
바꾸고 싶은 수치: (balance.json 항목 이름과 값)
```

## 밸런스 수치 바꾸는 법 (윤나희)

1. `config/balance.json`에서 값을 바꾼다 (예: `monster.moveSpeed` 5.5 → 5.3)
2. 이유를 한 줄 적어 PR을 올린다
3. 다음 테스트에서 바뀐 값으로 해 보고 기록에 남긴다

## 특히 봐야 할 것

- 처음 하는 사람이 10분 안에 자기 역할을 이해하는가
- 미끼(일부러 들키기)가 실제로 통하는가
- 괴물의 시야 모드 전환을 쓰는가, 안 쓰는가
- 탈출구 2인 개방이 재밌는가, 답답한가
- 핑이 느껴지는 순간이 있는가 (있으면 그때 무엇을 하고 있었는지)
