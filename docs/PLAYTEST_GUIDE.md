# DECOY 플레이테스트 가이드 (테스터용)

개발은 개발자 한 명이 하고, 테스터는 플레이테스트와 밸런스 피드백을 맡는다. 테스트 결과가 남아야 테스터 기여도도 기록으로 남는다.

## 테스터가 할 일

- **플레이테스트 · 버그 리포트**: 판을 하고 아래 기록 양식을 채운다. 버그는 GitHub Issues에 올린다
- **밸런스 피드백 · `config/balance.json` 수정 PR**: 바꾸고 싶은 수치를 기록하고, 직접 바꿔 PR을 올린다 (아래 "밸런스 수치 바꾸는 법")
- **괴물 역할 돌아가며 맡기**: 판마다 괴물을 맡는 사람을 바꾼다

## 테스트 한 번 하는 법

0. 개발자가 서버를 띄운다 (`npm start`, 같은 와이파이면 `http://<IP>:8080`, 인터넷이면 배포 주소 — `docs/DEPLOY.md`). 무료 배포(Render)는 15분 동안 아무도 없으면 잠드니, 시작 몇 분 전에 한 번 접속해 깨운다
1. 개발자가 보낸 링크로 접속 (`.../?room=ABCD`)
2. 역할을 고르고 시작. **괴물 역할은 판마다 돌아가며** 맡는다
3. 판이 끝나면 아래 기록 양식을 채운다
4. 버그는 GitHub Issues에 올린다 (제목: `[버그] 무엇이 어떻게`, 본문: 재현 방법, 스크린샷)

## 휴대폰으로 하는 법

- **가로로 든다.** 세로로 들면 "가로로 돌려 주세요" 안내가 뜬다. 판이 시작되면 전체 화면으로 바뀐다
- **조작**: 화면 왼쪽(40%) 아무 데나 엄지를 대면 그 자리에 이동 스틱이 생긴다. 오른쪽에는 버튼(생존자: 능력 · 구조 · 점수판, 괴물: 조준 스틱 · 돌진 · 포효 · 시야)이 있다. 괴물의 공격은 조준 스틱을 밖으로 끌었다가 놓는다. 첫 판 전에 안내 카드가 한 번 뜬다(다시 보려면 로비 설정의 '터치 조작 안내 다시 보기')
- **진동**: 맞거나 발각될 때 짧게 울린다. 로비 설정에서 끌 수 있다
- **끊기면**: 앱을 잠깐 다른 앱으로 바꿨다 돌아와도 30초 안이면 같은 자리로 돌아온다. 빠른 매칭을 기다리는 중에 화면이 꺼지면 대기열에서 빠진다("다시 찾기")
- **설치해서 하기(안드로이드 크롬)**: 메뉴 › '앱 설치'(또는 '홈 화면에 추가'). 설치한 앱은 주소창 없이 전체 화면으로 열리고, 한 번 온라인으로 연 뒤에는 비행기 모드에서도 열려 **봇과 연습**을 할 수 있다
- **구글 플레이 비공개 테스트에 참여한 경우**: 참여 링크 → '테스터 되기' → Play 스토어에서 설치. **14일 동안 지우지 말고** 가끔 한 판씩 한다(정식 출시 조건). 주소창이 보이면 개발자에게 알린다
- 휴대폰 리포트에는 **기종 · 안드로이드 버전 · 브라우저(크롬/삼성 인터넷)인지 설치 앱인지**를 같이 적는다

## 혼자 해 보기

- **봇과 연습**: 첫 화면에서 '봇과 연습' → 역할을 고르면 봇 셋과 바로 시작한다. 서버가 필요 없어 서버가 잠들어 있거나 인터넷이 없어도 된다. 기록은 남지 않는다
- **빠른 매칭**: 모르는 사람과 자동으로. 20초 안에 4명이 모이지 않으면 빈자리를 봇이 채운다. 다른 사람에게 내 이름은 "플레이어 n"으로 보인다

## 기록 양식 (판마다)

```
날짜 / 판 번호:
방식: (친구 방 / 빠른 매칭 / 봇과 연습)    기기: (PC / 휴대폰 기종 · 브라우저 또는 설치 앱)
괴물:            러너:           가드:           스카우트:
결과: (생존자 승리 n명 탈출 / 괴물 승리 / 시간 초과)
판 길이: 약 __분
가장 재밌던 순간:
답답했던 순간:
괴물이 너무 강했나 / 약했나 / 적당했나:
바꾸고 싶은 수치: (balance.json 항목 이름과 값)
```

## 밸런스 수치 바꾸는 법

1. `config/balance.json`에서 값을 바꾼다 (예: `monster.moveSpeed` 5.5 → 5.3)
2. 이유를 한 줄 적어 PR을 올린다. 바꾼 값은 `docs/GAME_DESIGN.md` 변경 이력에도 한 줄 남긴다
3. 다음 테스트에서 바뀐 값으로 해 보고 기록에 남긴다

- **바꾸면 안 되는 값**: `match.players`, `match.survivors`, `capturePoint.count`, `exit.count`는 맵 · 화면 구조에 묶여 있다. 서버가 시작할 때 검사해서 다르면 뜨지 않는다
- 서버는 시작할 때 `balance.json`을 읽으므로 값을 바꾸면 **서버를 다시 켠다**. 클라이언트는 접속할 때 서버 값을 받는다(`&debug=1` 오버레이의 "밸런스" 값으로 모두 같은 값인지 확인)
- 판단이 필요한 후보 값들은 `docs/HUMAN_CHECKS.md`의 "손맛 · 밸런스"에 정리되어 있다

## 알아 두면 좋은 것

- 화면이 끊기는 노트북은 로비의 그래픽 품질을 낮음으로 고른다(또는 주소 끝에 `&quality=low`)
- `&debug=1`을 붙이면 FPS · 핑이 보인다. 버그 리포트에 이 값을 같이 적는다
- 혼자 시험할 때는 `?bots=1`로 방을 만들면 빈 역할을 봇이 채운다
- "서버를 깨우는 중…" 화면이나 "서버에 다시 연결하는 중…" 안내가 뜨면 그대로 기다린다. 무료 서버가 잠들었다 깨어나는 중이고(1분쯤), 깨어나면 저절로 다시 연결된다. 서버가 잠들었다면 전에 있던 방은 사라졌으니, 방장이 새 방을 만들어 링크를 다시 보낸다
- 새로고침해도 30초 안이면 같은 자리로 돌아온다. 괴물이 나가면 판이 멈추고, 30초 안에 안 돌아오면 무효가 된다
- 첫 판에는 역할별 조작 안내가 5초 뜨고, 판 중에는 Tab을 누르고 있으면 점수판이 보인다

## 특히 봐야 할 것

- 처음 하는 사람이 10분 안에 자기 역할을 이해하는가
- 미끼(일부러 들키기)가 실제로 통하는가
- 괴물의 시야 모드 전환을 쓰는가, 안 쓰는가
- 탈출구 2인 개방이 재밌는가, 답답한가
- 핑이 느껴지는 순간이 있는가 (있으면 그때 무엇을 하고 있었는지)
