## M0 — 뼈대와 도구 (완료)
- npm 워크스페이스(shared · server · client · tests), TypeScript strict(`noUncheckedIndexedAccess` 포함), ESLint(any 금지, shared/server에서 Phaser import 금지), Prettier
- 스크립트: `dev`(서버 tsx watch + Vite), `build`(Vite + esbuild 서버 번들), `start`, `test`(Vitest), `test:e2e`(빌드 후 Playwright), `typecheck`, `lint`, `check`
- `config/balance.json`을 서버가 읽어 검증한다(`shared/src/balance.ts`). 문서에 없던 값 11개 추가(변경 이력 참고)
- 검증: typecheck · lint · format · 단위 3개 · E2E 스모크 2개(설치된 Chromium 사용 확인, 캔버스 · 콘솔 에러 0) 통과

## M1 — 접속과 이동 동기화 (완료)
- 방 만들기 · 코드 입장 · 링크 입장(`/?room=ABCD`), 4인 로비(HTML), 역할 선택(중복 불가), 준비, 방장 시작, 방장 이전. 자리 토큰은 탭별 sessionStorage + 보조 localStorage(DECISIONS D2)
- 서버 고정 틱 30Hz · 스냅샷 20Hz, 입력 `seq` 고정 1/30초 샘플링(렌더 프레임과 분리된 타이머), 입력 크레딧(틱당 평균 1개, 최대 3개 — 속도 핵 방지)
- 내 캐릭터 예측 + 보정(`shared/movement.ts` 공용, 오차는 150ms에 걸쳐 줄이고 1.5타일 넘게 어긋나면 바로 맞춤), 다른 캐릭터 100ms 보간(서버 시각 기준, ping 시계 동기화), `--lag` / `?lag`(왕복 ms, ±20ms, 순서 보존)
- `window.__DECOY__` 디버그 훅(`?debug=hook`), `?debug=1` 오버레이(FPS · 핑 · 서버 틱 · 예측 오차 · 밸런스 해시), 테스트 전용 서버 옵션 `--test-hooks`(위치 지정 · `/test/state`) · `--truth-log`
- 검증: 단위 21개(지연 큐 순서, 예측 = 서버 결과, 보간 공백 처리, 입력 크레딧, 로비 규칙, 스냅샷 20Hz) + E2E 4개(4 컨텍스트 동기화 오차 자기 0.05 · 남 0.1타일 이하, lag=200에서 80ms 안에 내 위치 반영 후 수렴, 한 브라우저 탭 4개 = 4자리 · 새로고침 복귀, 잘못된 방 코드 안내)
- 발견: 헤드리스 컨테이너(GPU 없음)에서 WebGL 탭 4개는 1~3FPS라, 여러 탭 E2E는 Canvas 렌더러(`?renderer=canvas`)로 돌린다

## M2 — 맵 · 역할 · 기본 조작 (완료)
- `shared/src/map.ts` 48×32 맵: 거점 A 쪽은 좁은 통로 · 코너가 있는 방(입구 4곳, 폭 2), B 쪽은 넓은 방, 북 · 남 중앙은 벽과 복도. 구역 5곳 모두 돌 수 있는 기둥이 있다. 감옥 4×4 철창(시야 통과) + 남쪽 문 2칸(수감자만 차단)
- 원-타일 충돌(미끄러짐, 0.2타일 서브스텝으로 돌진 속도에서도 벽 통과 없음), 생존자↔괴물 비통과, 스폰(감옥 안 / 괴물 (45,28)), 괴물 시작 5초 대기(조준 · 모드 전환만)
- 괴물 마우스 조준(540°/초 상한), 회전 감속(최근 0.25초 입력과 90° 초과 차이 → 0.35초 60%), 우클릭 시야 모드 전환(0.4초 보간, 전환 중 다시 누르면 되돌아감)
- 코드로 그린 맵(바닥 · 벽 외곽선 글로우 · 기둥 · 철창), 생존자 원 + 노치, 괴물 후드 + 눈 + 조준 노치, 거점 영역 · 진행 링 · 마름모 배지, 탈출구 문 + 달리는 사람, 감옥 자물쇠 배지, 시야 원(역할색 12%), 괴물 부채꼴 · 근접 원
- M1 검토 반영: 잘못된 input · test 메시지로 서버가 죽던 문제, 예측 가능한 자리 토큰(시드 난수 → crypto), 같은 토큰 두 탭이 서로 자리를 빼앗는 반복, `--lag`에서 닫힌 소켓의 join이 유령 자리를 남기던 문제, 판 중 로비 메시지로 괴물에게 역할 · 접속 상태가 새던 문제, 로비 오류 문구가 남던 문제
- 검증: 단위 66개(맵 연결성 · 통로 폭 · 구역별 기둥 · 감옥 문 · 탈출구 문, 이동 속도 · 충돌 · 미끄러짐 · 비통과, 회전 감속 경계 5종, 조준 회전 상한, 시야 모드 0.2초=80°·7타일, 스폰 · 대기) + E2E 2개(괴물 조준 각도가 네 화면에서 ±2° 안, 우클릭 모드 전환 0.4초)

## M3 — 시야 · 안개 · 정보 차단 (완료)
- `shared/src/visibility.ts`: 대상 중심점 기준 판정(반경 하드 컷, 벽 차단, 철창 · 감옥 문은 시야 통과), 부채꼴 모양은 탐색 ↔ 추적 보간값으로 판정과 그림에 똑같이 사용. 시야 다각형은 벽 모서리 광선 + 호 표본(1ms 미만)
- `server/interest.ts`: 틱마다 시야 사실을 한 번 계산해 받는 사람별 스냅샷. 괴물에게는 시야 안 생존자만 **임시 ID**로(시야에 새로 들어올 때마다 새 ID), 역할은 능력 노출 창에만, 부상 · 팀 정보 · 탈출구 진행도 없음, 익명 상태 목록. 생존자에게는 팀원 전원 + 합집합 안일 때만 괴물과 부채꼴, 본인 발각 여부
- 클라이언트 바닥 합성 레이어(맵 + 영역 + 시야 + 안개를 한 장으로), 생존자 시야 합집합(반경 안쪽 1.2타일 부드럽게, 겹쳐도 누적 없음), 괴물 부채꼴 + 근접 원 하드 컷, 항상 표시 배지(미관측 45%), 생존자 화면 부채꼴 노랑 ↔ 빨강(0.1초 / 0.4초), 발각 테두리 · 배너, 괴물 화면 생존자 흰색
- M1 검토 2차 반영: 보간 시각(스냅샷 시계), 입력 막힘 뒤 영구 밀림(빚 처리), 좁은 틈 통과(충돌 수렴 + 걸음 취소), 지연 큐 순서, 내 캐릭터 틱 사이 보간, 명목 틱 시각, HTTP · WS 견고성(잘못된 URL, 하트비트, 송신 버퍼, 빈 방 정리, 정적 파일 오류)
- 검증: 단위 83개(벽 뒤 · 부채꼴 경계 · 근접 원 · 모드 전환 중 판정, 다각형 = 판정 일치율 99% 이상, 임시 ID 교체, 역할 노출 창, 익명 상태 목록, 수감 중 시야, 서버 견고성 3개) + E2E: **각 클라이언트가 받은 WebSocket 프레임 원문 전체를 서버 정답 기록(틱별)과 독립 판정기(0.01타일 표본 시선)로 대조 — 괴물에게 시야 밖 생존자 좌표 0건, 생존자에게 시야 밖 괴물 좌표 0건, 원문에 생존자 실제 ID 0건**(숨은 생존자가 있는 프레임 30% 이상 · 보이는 생존자 프레임 10% 이상으로 빈 통과 방지)
- FPS(헤드리스, 소프트웨어 합성, Canvas, 4탭 동시): 전체 해상도 41.9 / `scale=0.5` 60.4 → 게이트는 scale 0.5 기준 55 이상 통과. 전체 해상도 55는 이 컨테이너(4코어, GPU 없음)에서 못 미쳐 실제 PC 확인을 HUMAN_CHECKS에 남겼다

## M4 — 공격 · 수감 · 구조 (완료)
- `systems/combat.ts`: 좌클릭 → 준비 0.4초(조준 고정, 이동 가능) → 생존자 몸 원이 1.2타일 · 90° 부채꼴과 겹치고 시선이 막히지 않으면 범위 안 전원 타격 → 쿨 1.5초(타격부터). 체력 2, 두 번 맞으면 감옥 빈 자리로 즉시 이동, 수감 2회 뒤 세 번째는 사망. 수감 · 보호 · 사망 · 탈출 생존자는 맞지 않음
- `systems/prison.ts`: 문 앞 반경 1.2에서 E 3초(구조자마다 따로, 실제 피격 · 이탈 · E 떼면 0) → 감옥 안 전원 해방, 체력 2, 4초 보호, 문 바로 바깥으로. 캠핑: 수감자가 있을 때 철창 경계 4타일 안 5초 넘게 → 70%(회전 감속과 곱), 3초부터 경고
- `systems/match.ts`: 승패 판정 함수 전체(3명 동시 수감 · 자유 생존자 0명 · 2명 사망 · 2명 탈출 + 최후의 30초 · 12분 · 끊김 이벤트)를 미리 만들어 연결 지점으로 둠. 판이 끝나면 방이 결과를 보낸다
- 클라이언트: 공격 준비 범위(흰색 25%, 양쪽 화면), 구조 진행 링, 보호 깜빡임(괴물 화면은 흰색), 괴물 화면 캠핑 · 거점 지키기 경고
- 봇: `server/pathfind.ts`(A*), `server/botBrains.ts`(개발용 순찰 봇 · 사냥 · 머물기 · 단계별 두뇌, 모두 자기 스냅샷만 사용), `server/sim.ts`(소켓 없이 실제 방과 같은 20Hz 스냅샷 · 30Hz 입력으로 빠르게 돌리는 판)
- 검증: 단위 16개(준비 · 회피 · 조준 고정 · 쿨 · 대기 중 불가 · 다중 타격 · 벽 차단 · 2타 수감 · 3번째 사망 · 보호 무효 · 구조 3초 · 이탈 초기화 · 피격 중단 · 보호 4초 · 빈 감옥 · 캠핑 · 3명 수감 승리) + 봇 시나리오 "두 명 수감 → 한 번에 해방 → 보호 중 피격 무효" + E2E(브라우저 공격 → 부상 → 수감, 괴물 화면 익명 목록)

## M5 — 거점 · 탈출구 · 승패 (완료)
- `systems/capture.ts`: 자유 생존자 1명 40초 · 2명 이상 1.5배, 괴물이 안에 있으면 정지(5초 넘게 지키면 해제, `monsterBlockGrace`), 비어도 게이지 유지, 점령 시작은 괴물에게만(8초 재알림 제한), 완료는 양쪽 + 생존자에게 점령 순서대로 메모와 비밀번호 두 자리, 두 거점 완료 시 탈출구 활성 + 알림
- `systems/exit.ts`: 활성 탈출구 반경 1.5 안 자유 생존자 2명 이상 3초 → 열림(인원 모자라면 0으로, 괴물 있어도 진행), 열린 문 칸(외벽)으로 걸어 들어가면 탈출. 괴물은 문을 지나지 못한다
- 승패 전부(`systems/match.ts`) · 최후의 30초 · 12분 제한 · 결과 등급 · 결말 문구(시간 초과 + 탈출 0명일 때만 END_TIMEOUT), 결과 화면(승리 팀 · 등급 · 결말 · 플레이어별 맞은 · 맞힌 횟수 · 구조 · 점령 기여 · 결과 · 판 길이), 다시 하기(같은 방 로비, 역할 유지)
- 검증: 단위 22개(점령 40초/26.7초, 괴물 정지와 5초 해제, 게이지 유지, 알림 대상 · 쿨다운 · 메모 순서, 탈출구 비활성 · 2인 3초 · 이탈 초기화 · 혼자 불가 · 괴물 있어도 진행 · 문 칸 탈출 · 괴물 통과 불가, 승패 표 모든 줄 + 보충 규칙) + 봇 전체 판 2회(생존자 승리 "완전 탈출" 3명 탈출, 괴물 승리 전원 수감) + E2E(브라우저에서 거점 → 탈출구 → 탈출 → 결과 → 다시 하기)
