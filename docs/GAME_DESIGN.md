# DECOY v2 게임 설계서 (웹판)

생존자 3명과 괴물 1명이 브라우저로 접속해 겨루는 온라인 비대칭 탈출 게임. **이 문서가 규칙의 원본이다.** 수치는 `config/balance.json`이 원본이고, 이 문서의 숫자는 이해를 돕는 사본이다. `docs/reference/`의 v1 문서와 어긋나면 이 문서를 따른다.

## 0. v1에서 바뀐 것 (요약)

| 영역 | v1 (Unity, AI 괴물 흔적 포함) | v2 (웹, 사람 괴물) |
|---|---|---|
| 감지 | 0.2초 감지 · 0.5초 발각, 실루엣, 흔적 3초 | **시야에 들어오면 바로 보임.** 부채꼴 색 2단계 |
| 괴물 시야 | 70도 · 8타일 고정 | **탐색(110° · 5타일) / 추적(50° · 9타일) 전환** |
| 괴물 능력 | 이동 · 조준 · 공격 | + **돌진, 포효** |
| 생존자 | 능력 동일 + 아이템 상자 | **러너 · 가드 · 스카우트** 고유 능력, 아이템 없음 |
| 거점 | 3개 | **2개**, 둘이 함께하면 1.5배 |
| 탈출구 | 1곳, 거점 완료 시 개방 | **2곳**, 두 명이 함께 3초 머물러야 개방 |
| 수감 | 3회까지, 4회째 사망 | **2회까지, 3회째 사망**. 구조 시 전원 해방, 4초 보호 |
| 호스트 | 방장이 호스트, 괴물은 호스트 불가 | **전용 서버가 판정**, 제한 없음 |
| 판 길이 | 제한 없음 | **12분 제한** |

## 1. 한 판의 흐름

1. 로비에서 4명이 모인다. 한 명은 괴물, 세 명은 러너 · 가드 · 스카우트를 하나씩 고른다
2. 생존자 3명은 중앙 감옥에서, 괴물은 맵 구석에서 시작한다. 괴물은 처음 5초 동안 움직일 수 없다
3. 생존자는 흩어져 거점 A · B를 점령한다. 점령을 시작하면 괴물에게 알림이 간다
4. 괴물은 생존자를 쫓아 공격한다. 두 번 맞은 생존자는 감옥으로 끌려간다. 다른 생존자가 구조할 수 있다
5. 두 거점을 모두 점령하면 북 · 남 탈출구 두 곳이 활성화된다. 생존자 두 명이 한 탈출구에 함께 3초 머무르면 그 문이 열린다
6. 열린 문으로 두 명 이상 탈출하면 생존자 승리. 두 명 이상 죽거나 세 명이 동시에 갇히면 괴물 승리

목표 판 길이: 8~10분.

## 2. 조작

| 입력 (PC) | 터치 (휴대폰 · 태블릿, M11) | 생존자 | 괴물 |
|---|---|---|---|
| WASD | 왼쪽 이동 스틱 (화면 왼쪽 40% 안 누른 자리에 생김, 360°) | 이동 | 이동 |
| 마우스 | 괴물: 오른쪽 조준 스틱 (놓고 있으면 이동 방향) | — (바라보는 방향 = 이동 방향) | 시야 · 공격 방향 조준 |
| 좌클릭 | 조준 스틱을 밖으로 끌었다가 놓기 (조준이 그 방향 ±10°에 오면, 최대 0.35초 뒤. 짧게 톡 = 지금 방향, 가운데로 되돌려 놓으면 취소) | — | 공격 |
| 우클릭 | 시야 버튼 | — | 시야 모드 전환 (탐색 ↔ 추적) |
| E (누르고 있기) | 구조 버튼 누르고 있기 | 구조 | — |
| Space | 능력 버튼 | 고유 능력 | — |
| Shift | 돌진 버튼 (끌어서 놓기 = 끈 방향, 그냥 탭 = 지금 방향 또는 잡고 있는 조준 스틱 방향) | — | 돌진 |
| Q | 포효 버튼 | — | 포효 |
| Tab (누르고 있기) | 점수판 버튼 (눌러서 켜고 끄기) | 점수판 · 상태 | 점수판 · 상태 |

터치는 같은 입력 프레임(`InputFrame`)으로 보낸다. 서버는 PC인지 휴대폰인지 모르고, 판정은 그대로다. 조작 해석 수치(데드존 15%, 발사 대기 ±10° · 최대 0.35초, 짧은 탭 0.25초)는 `client/src/touchInput.ts`(판정과 무관, DECISIONS M11)

## 3. 시야와 정보

### 3.1 공통
- 맵 구조(벽 · 바닥 · 기둥 · 감옥 · 거점 · 탈출구)는 항상 어둡게 보인다. 캐릭터와 움직이는 것은 **지금 보고 있는 곳에서만 보인다** (기억 상태 없음)
- 벽은 시야를 막는다
- 감옥, 거점 A · B, 탈출구 두 곳의 위치 배지는 항상 보인다
- 서버는 각 플레이어에게 **볼 수 있는 대상만 보낸다.** 안 보이는 상대의 위치는 클라이언트에 아예 오지 않는다

### 3.2 생존자 화면
- 생존자 각자 원형 시야(반지름 6타일, 스카우트 7.5타일)를 가지고, **세 명의 시야를 합쳐서** 본다
- 팀원 위치는 시야와 무관하게 항상 보인다 (팀원끼리는 서로의 위치를 안다)
- 괴물은 세 명의 시야 합집합 안에 있을 때만 보인다. 이때 괴물의 부채꼴도 보인다
- **부채꼴 색 2단계**: 노랑 `#EAB308`(아무도 안 보임) / 빨강 `#EF4444`(생존자 누군가가 괴물에게 보이는 중)
- 내가 괴물에게 보이는 중이면 화면 가장자리에 빨간 테두리와 "발각" 배너가 뜬다

### 3.3 괴물 화면
- 괴물은 부채꼴 + 근접 원(반지름 1.5타일)만 본다
- 부채꼴 안 생존자는 **바로** 보인다. 단, **세 명 모두 같은 흰색**으로 표시해 누구인지 바로 알 수 없게 한다. 생존자가 능력을 쓰면 그 순간 그 생존자에게 역할 색 테두리가 1초 보인다
- 시야 모드
  - **탐색**: 110°, 5타일 — 가까운 곳을 넓게 훑기
  - **추적**: 50°, 9타일 — 멀리 길게 보기
  - 우클릭으로 전환, 0.4초에 걸쳐 모양이 바뀐다. 생존자 화면의 부채꼴 모양도 같이 바뀐다
- 조준 회전 속도 상한 540°/초 (순간 360도 훑기 방지)

## 4. 이동

- 생존자 이동속도 5타일/초, 괴물 5.5타일/초 (110%)
- **괴물 회전 감속**: 이동 방향을 90° 넘게 틀면 0.35초 동안 속도 60%. 기둥을 돌면 거리를 벌릴 수 있게 하는 핵심 규칙
- 생존자와 괴물은 서로 통과하지 않는다. 생존자끼리는 통과한다

## 5. 괴물

### 5.1 공격
- 좌클릭 → 준비 0.4초(양쪽 화면에 범위 표시) → 전방 90°, 1.2타일 범위 타격 → 쿨타임 1.5초
- 준비 중에 범위 밖으로 나가면 피한다
- 수감 중 · 보호 중 · 사망 · 탈출한 생존자는 맞지 않는다

### 5.2 돌진 (Shift)
- 조준 방향으로 0.25초 동안 4타일 이동, 벽에 닿으면 멈춤. 쿨타임 12초
- 추격을 끝내는 수단. 쓰고 나면 12초 동안 다시 못 쓰므로 생존자에게 기회가 생긴다

### 5.3 포효 (Q)
- 반경 10타일 안 생존자 위치를 괴물 화면에 1.5초 표시 (벽 무시, 흰 원 펄스)
- 대가: 모든 생존자 화면에 "괴물이 포효했다" 경고와 함께 **괴물 위치가 1초 표시**된다
- 쿨타임 30초

### 5.4 감옥 캠핑 방지
- 괴물이 감옥 반경 4타일 안에 5초 넘게 있으면 이동속도 70%
- 3초부터 괴물 화면에 주황 경고, 반경을 벗어나면 즉시 복구

## 6. 생존자

### 6.1 체력과 수감
- 체력 2. 한 번 맞으면 부상(이동속도 그대로, 표시만), 두 번 맞으면 감옥으로 즉시 이동
- **수감 2회까지.** 세 번째로 잡히면 사망
- 수감 중에도 시야는 유지되어 팀에 감옥 주변 정보를 준다
- 세 명이 동시에 감옥에 있으면 괴물 승리

### 6.2 구조
- 감옥 문 앞에서 E를 3초 누르고 있으면 감옥 안 **전원**이 풀려난다
- 구조 중 공격받으면 중단된다
- 풀려난 생존자는 체력 2로 회복하고 **4초 보호**(피격 무효, 몸이 반투명)
- 구조가 끝나면 괴물 화면에 "구조됨" 알림

### 6.3 고유 능력 (Space)

| 역할 | 색 | 능력 | 수치 | 쓰임 |
|---|---|---|---|---|
| 러너 | `#3B82F6` | 질주 | 3초간 이동속도 ×1.45, 쿨 20초 | 미끼, 추격 탈출 |
| 가드 | `#A855F7` | 밀치기 | 2타일 안 괴물을 1.5초 기절(이동 · 조준 · 공격 · 능력 불가), 쿨 35초 | 구조 엄호, 동료 보호 |
| 스카우트 | `#22C55E` | 탐지 | 4초간 괴물 위치를 팀 전원 화면에 표시(벽 너머), 쿨 30초. 기본 시야 7.5타일 | 점령 타이밍 잡기 |

- 능력을 쓰는 순간 괴물 화면에서 그 생존자에게 역할 색 테두리가 1초 보인다 (정체 노출이라는 대가)

## 7. 거점

- 거점 A(서쪽), B(동쪽). 반경 2.5타일 원
- 안에 생존자가 있으면 게이지가 오른다. 1명이면 40초, **2명 이상이면 1.5배 속도**(약 27초)
- 괴물이 안에 있으면 진행이 멈춘다. 생존자가 없어도 게이지는 줄지 않는다
- **알림**: 점령 시작 → 괴물 화면에 해당 거점 배지 깜빡임 / 점령 완료 → 양쪽 화면 배너
- 거점을 완료할 때마다 스토리 메모가 뜬다 (`STORY_TEXT.md`)

## 8. 탈출구

- 북쪽 · 남쪽 두 곳. 두 거점을 모두 점령하면 활성화(회색 → 초록)
- **생존자 두 명이 같은 탈출구 반경 1.5타일 안에 함께 3초** 머무르면 그 문이 열린다. 중간에 한 명이 나가면 진행이 0으로 돌아간다
- 한 번 열린 문은 끝까지 열려 있고, 누구든 들어가면 탈출한다
- 문이 열리면 양쪽 화면에 배너

## 9. 승패

| 조건 | 결과 |
|---|---|
| 생존자 2명 이상 탈출 | 생존자 승리 (남은 생존자에게 최후의 30초) |
| 생존자 2명 이상 사망 | 괴물 승리 |
| 생존자 3명 동시 수감 | 괴물 승리 |
| 12분 경과 | 탈출 못 한 생존자는 사망 처리 후 위 조건으로 판정 |
| 괴물 접속 끊김 | 판 종료 (무효) |
| 생존자 접속 끊김 | 30초 안에 재접속하면 이어서, 아니면 사망 처리 |

**최후의 30초**: 두 명이 탈출해 승리가 확정되면 남은 생존자는 30초 동안 탈출을 시도할 수 있다. 성공하면 결과 등급이 올라간다.

**결과 등급** (생존자 화면): 3명 탈출 "완전 탈출" / 2명 "탈출 성공" / 1명 이하 "탈출 실패"

## 10. 맵

크기 48 × 32 타일, 화면 고정(스크롤 없음), 1타일 = 32px → 맵 영역 1536 × 1024.

```
     0         12        24        36        47
  0  ┌──────────────────[EXIT N]──────────────────┐
     │   기둥        복도·벽 많음        기둥       │
  8  │        ┌───┐                ┌───┐           │
     │        │   │    ┌──────┐    │   │           │
 16  │ [A]    └───┘    │ 감옥 │    └───┘    [B]    │
     │ 좁은 통로        └──────┘           넓은 방  │
 24  │        기둥                  기둥            │
     │                                         [M]  │
 31  └──────────────────[EXIT S]──────────────────┘
      A = 거점 A (8,16)   B = 거점 B (40,16)   감옥 (24,16)
      EXIT N (24,1)       EXIT S (24,30)       M = 괴물 시작 (45,28)
```

- 거점 A 구역: 좁은 통로와 코너 위주 (추격전)
- 거점 B 구역: 넓은 방 (시야에 쉽게 노출, 대신 둘이 함께 점령하기 좋음)
- 북 · 남 탈출구 사이 거리가 멀어 괴물이 둘을 동시에 지킬 수 없다
- **각 구역에 돌아갈 수 있는 기둥을 최소 1개.** 통로 폭은 최소 2타일
- 감옥은 철창으로 둘러싸고 문은 1곳(남쪽)

## 11. 로비

- "방 만들기" → 4글자 방 코드와 공유 링크(`/?room=ABCD`)
- 입장 후 역할 선택: 괴물 1, 러너 · 가드 · 스카우트 각 1. 같은 역할 중복 불가
- 4명이 준비하면 방 만든 사람이 시작
- 개발용: `?bots=1`이면 빈자리를 봇으로 채운다 (괴물 봇: 제자리 회전 · 순찰, 생존자 봇: 정해진 경로 순찰)
