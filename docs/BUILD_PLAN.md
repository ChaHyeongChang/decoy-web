# DECOY v2 제작 계획 (자율 진행용)

Claude Code가 한 세션에서 처음부터 끝까지 진행하기 위한 마일스톤이다. 각 마일스톤은 **작업 → 자동 검증 → 커밋** 순서로 끝낸다. 자동 검증이 통과해야 다음으로 간다.

## 진행 규칙

- 마일스톤마다 끝나면 이 문서의 체크박스를 갱신하고, 결과를 `docs/PROGRESS.md`에 3~5줄로 남긴 뒤 커밋한다
- 자동 검증이 실패하면 고친다. 같은 문제로 세 번 넘게 막히면 `docs/PROGRESS.md`에 막힌 이유를 적고, 그 항목을 `> 보류:`로 표시한 뒤 다음으로 넘어간다 (멈추지 않는다)
- 설계서와 다르게 만든 것은 `docs/DECISIONS.md`에 이유와 함께 적는다
- 사람이 직접 봐야 판단할 수 있는 것(손맛, 재미, 밸런스)은 `docs/HUMAN_CHECKS.md`에 모아 두고 진행을 멈추지 않는다
- 수치는 반드시 `config/balance.json`에서 읽는다. 코드에 숫자를 박지 않는다
