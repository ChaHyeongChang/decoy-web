# DECOY v2 비주얼 스펙 (웹판)

v1 비주얼 스펙(`reference/v1_비주얼스펙.md`)의 톤을 이어 가되, v2 규칙에 맞게 바뀐 부분을 반영했다. 컨셉 이미지(`images/`)는 생성형 AI로 만든 분위기 참고이며, 괴물이 여러 마리로 그려진 것은 초기 안이다.

## 1. 원칙

- 정직교 탑다운, 화면 고정(스크롤 · 줌 없음). 1타일 = 32px, 맵 1536 × 1024, 논리 해상도 1920 × 1080에 맞춰 레터박스
- **모든 그래픽은 코드로 그린 단색 도형**으로 시작한다 (Phaser Graphics). 그라디언트 · 그림자 · 질감 없음. 네온 느낌은 외곽선 + 약한 글로우(postFX)로만
- 색만으로 구분하지 않는다. 생존자 = 원, 괴물 = 후드 삼각형, 거점 = 마름모 + 글자, 탈출구 = 문 아이콘
- 외부 이미지 에셋은 선택 사항이다. 넣더라도 이 문서의 색 · 형태 규칙을 따른다

## 5. HUD

### 5.1 생존자
| 위치 | 요소 |
|---|---|
| 상단 중앙 | 거점 A · B 게이지, 남은 시간 |
| 좌측 상단 | 팀 카드 3장: 역할 아이콘, 체력 칸 2개, 수감 횟수(0/2), 능력 쿨타임 |
| 하단 중앙 | 내 능력 아이콘과 쿨타임, 구조 진행 게이지(구조 중일 때) |
| 우측 상단 | 미니맵 (메인 화면과 같은 정보 규칙) |
| 화면 중앙 상단 | 배너 (발각, 점령, 문 열림, 포효) |

### 5.2 괴물
| 위치 | 요소 |
|---|---|
| 상단 중앙 | 거점 A · B 게이지와 점령 중 깜빡임, 남은 시간 |
| 좌측 상단 | 생존자 상태 3칸(정상 · 부상 · 수감 · 사망 · 탈출, 수감 횟수). **위치와 역할은 표시하지 않음** |
| 하단 중앙 | 공격 쿨, 돌진 쿨, 포효 쿨, 현재 시야 모드(탐색/추적) |
| 하단 중앙 위 | 캠핑 경고 (3초부터) |
| 우측 상단 | 미니맵 (괴물 시야 안에서 본 것만) |

## 6. 로비 · 결과 화면

- **로고**: `docs/images/logo_decoy.png` (원형, 배경 투명, 청록 네온 새 문양). 로비 상단 중앙에 크게, 결과 화면 상단에 작게, 브라우저 탭 아이콘(favicon)으로도 쓴다. 로고 옆 글자 "DECOY"는 코드로 얹는다 (로고 이미지에 글자 없음)

- 로비: 방 코드 크게, 링크 복사 버튼, 역할 카드 4장(괴물 · 러너 · 가드 · 스카우트, 각 능력 한 줄 설명), 준비 상태
- 결과: 승리 팀, 결과 등급(생존자), 결말 문구(`STORY_TEXT.md`), 플레이어별 기록(맞은 횟수, 구조 횟수, 점령 기여, 탈출 여부), "다시 하기"
- 첫 판 시작 시 역할별 조작 안내 오버레이 5초 (다시 보기는 Tab 화면에서)
