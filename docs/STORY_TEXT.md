# DECOY v2 스토리와 게임 내 텍스트

스토리텔링 과제(2026.09.30)의 설정을 v2 규칙(거점 2개, 생존자 고유 능력)에 맞게 고쳤다. 피드백 "로스트 바이킹 참고"에 따라 세 생존자에게 성격과 능력을 나눴다. 게임에는 **플레이를 멈추지 않는 짧은 텍스트로만** 넣는다. 텍스트는 코드에 박지 말고 `client/src/data/storyText.ts` 한 곳에 모은다.

## 1. 설정 요약

- **무대** — 이름 없는 지하 수용소. 조명이 거의 꺼져 주변 몇 걸음만 보인다 (안개)
- **괴물** — 수용소의 사냥꾼. 넓게 훑거나 멀리 노려보며(시야 모드) 붙잡은 사람을 중앙 감옥에 가둔다. 세 번째로 붙잡힌 사람은 돌아오지 못한다
- **기록자** — 먼저 갇혔던 수감자. 탈출구 비밀번호를 알아내 괴물이 한꺼번에 지우지 못하게 **두 조각**으로 나눠 두 장소에 새겼다. 탈출구 문은 혼자 힘으로는 열리지 않는다는 것도 알았지만, 혼자였기에 끝내 나가지 못했다
- **세 생존자** — 서로 처음 보는 세 사람. 각자 할 줄 아는 게 다르다

| 역할 | 한 줄 소개 (로비 카드) |
|---|---|
| 러너 | 배달 일을 하던 사람. 누구보다 빨리 달린다. 미끼가 되는 건 언제나 이 사람이다 |
| 가드 | 건물 경비원. 겁이 없다. 괴물 앞을 막아서는 유일한 사람 |
| 스카우트 | 사진가. 남들이 못 보는 것을 먼저 본다. 괴물이 어디 있는지 가장 먼저 안다 |
| 괴물 | 수용소의 사냥꾼. 도망친 자들을 다시 가둔다 |

## 3. 서버 연결 안내

무료 호스팅(Render)이 잠들었다 깨어나는 동안의 안내. 게임 안 패널은 `client/src/data/storyText.ts`(`UI_TEXT`)에서, 깨우기 화면(`client/public/wake.html`)은 게임 코드 없이 혼자 도는 페이지라 같은 문구를 직접 적는다. 바꾸면 둘 다 고친다.

| 상황 | 화면 | 제목 | 본문 |
|---|---|---|---|
| 처음 접속을 2.5초 넘게 기다림 | 로비 자리 패널 (로고) | 서버를 깨우는 중… | 무료 서버는 15분 동안 아무도 접속하지 않으면 잠들어요. 깨어나는 데 1분쯤 걸릴 수 있어요. 이 화면을 그대로 두면 자동으로 연결돼요. |
| 연결이 끊긴 뒤 2.5초 넘게 못 붙음 | 화면 가운데 패널 | 서버에 다시 연결하는 중… | (같음) |
| 잠든 서버에 페이지를 다시 엶 | 깨우기 화면 (`wake.html`) | 서버를 깨우는 중… | (같음) |
| 마지막 방으로 돌아가는데 옛 연결이 남아 2.5초 넘게 못 들어감 (M12, 터치 · 설치 앱) | 화면 가운데 패널 | 서버에 다시 연결하는 중… | (같음) |
| 위 패널을 띄울 때 기기가 오프라인 (M12) | 같은 패널 · 깨우기 화면 | (같음) | 인터넷 연결이 끊겨 있어요. 와이파이나 데이터를 확인해 주세요. |
| 연결이 끊김 (로비 · 판) | 화면 위 알림 (2.5초) | 연결이 끊겼습니다. 다시 연결하는 중… | — |

첫 화면(M13b)은 연결과 상관없이 바로 그리고, 가운데 패널 대신 상태 줄 한 줄로 알린다(패널은 방 · 판 화면에서만). 상태 줄과 오류 줄은 이름 칸 바로 아래, 빠른 매칭 위에 둔다(검토 반영: 높이 360 이하 휴대폰 가로에서도 첫 화면 안). 연결이 필요한 버튼(방 만들기 · 입장)은 연결 전에 꺼 두고, **봇과 연습**은 어느 상태에서나 된다.

| 상태 | 첫 화면 상태 줄 |
|---|---|
| 연결됨 | 서버 연결됨 |
| 연결을 기다린 지 90초 이하 | 서버를 깨우는 중… {n}초 — 기다리는 동안 봇과 연습을 할 수 있어요 |
| 인터넷은 되는데 90초 넘게 못 붙음 (서버 꺼짐 · 운영 종료) | 서버에 연결할 수 없어요 — 봇과 연습은 할 수 있어요 |
| 기기가 오프라인 | 인터넷 연결이 없어요 — 봇과 연습만 할 수 있어요 |

- 기다린 시간은 `{n}초째 기다리는 중`으로 센다
- 방 링크(`?room=`) · 마지막 방 복귀로 들어가는 중이라 아직 방에 들어가지 못한 패널(처음 접속 · 옛 연결이 남아 다시 시도)에는 "첫 화면으로" 버튼을 둔다(검토 반영). 누르면 방 코드를 첫 화면 코드 칸에 남기고 첫 화면(상태 줄 + 봇과 연습)으로 간다 — 오프라인 · 서버 꺼짐에서 패널에 갇히지 않게. 판 중 다시 연결하는 패널에는 없다
- 링크 · 재연결로 들어가려던 방이 없을 때(서버가 잠들었다 깨어나면 방이 사라진다) 로비 오류 뒤에 붙는 문구: "서버가 잠들었다 깨어나거나 다시 시작하면 방이 사라져요. 새 방을 만들어 링크를 다시 보내 주세요." (직접 입력한 코드가 틀린 경우에는 붙이지 않는다)
- 깨우기 화면 추가 문구: 인터넷이 끊겼을 때 "인터넷 연결이 끊겨 있어요. 와이파이나 데이터를 확인해 주세요.", 90초가 넘으면 "서버에 연결할 수 없어요. 기다리는 동안 봇과 연습을 하거나, 아래 버튼으로 다시 시도해 주세요." + **다시 시도** 버튼(새로고침, M13d). 앱 셸이 캐시돼 있으면(한 번 연 기기) 처음부터 **기다리는 동안 봇과 연습** 버튼(M13d)

## 8. 판 밖 성장 · 보상 (메타)

판이 끝나면 결과 화면에 내 평가 넷 · 경험치가, 첫 화면 · 로비에 내 레벨이 보인다(`GAME_DESIGN.md` 12장, `docs/META_PLAN.md`). 평가 이름 · 단계 이름은 여기서 정하고 수치는 `config/progression.json`이다. 결과의 '등급'(완전 탈출 · 탈출 성공 · 탈출 실패)과 헷갈리지 않게 평가는 '단계'라 부른다. 판 중 HUD에는 아무것도 더하지 않는다.

## 9. 선택형 구글 로그인 · 계정 저장 (`ACCOUNT_TEXT`)
