# DECOY v2 스토리와 게임 내 텍스트

스토리텔링 과제(2026.09.30)의 설정을 v2 규칙(거점 2개, 생존자 고유 능력)에 맞게 고쳤다. 피드백 "로스트 바이킹 참고"에 따라 세 생존자에게 성격과 능력을 나눴다. 게임에는 **플레이를 멈추지 않는 짧은 텍스트로만** 넣는다. 텍스트는 코드에 박지 말고 `client/src/data/storyText.ts` 한 곳에 모은다.

## 1. 설정 요약

- **무대** — 이름 없는 지하 수용소. 조명이 거의 꺼져 주변 몇 걸음만 보인다 (안개)
- **괴물** — 수용소의 사냥꾼. 넓게 훑거나 멀리 노려보며(시야 모드) 붙잡은 사람을 중앙 감옥에 가둔다. 세 번째로 붙잡힌 사람은 돌아오지 못한다
- **기록자** — 먼저 갇혔던 수감자. 탈출구 비밀번호를 알아내 괴물이 한꺼번에 지우지 못하게 **두 조각**으로 나눠 두 장소에 새겼다. 탈출구 문은 혼자 힘으로는 열리지 않는다는 것도 알았지만, 혼자였기에 끝내 나가지 못했다
- **세 생존자** — 서로 처음 보는 세 사람. 각자 할 줄 아는 게 다르다

| 역할 | 한 줄 소개 (로비 카드) |
|---|---|
| 러너 | 배달 일을 하던 사람. 누구보다 빨리 달린다. 미끼가 되는 건 언제나 이 사람이다 |
| 가드 | 건물 경비원. 겁이 없다. 괴물 앞을 막아서는 유일한 사람 |
| 스카우트 | 사진가. 남들이 못 보는 것을 먼저 본다. 괴물이 어디 있는지 가장 먼저 안다 |
| 괴물 | 수용소의 사냥꾼. 도망친 자들을 다시 가둔다 |

- 거점 메모는 **점령 순서**대로 나온다 (A/B와 무관). 그래야 마지막 메모가 항상 마지막에 나온다
- 비밀번호 숫자는 매 판 무작위 두 자리씩, 표시만 한다 (입력 장치 없음)

## 3. 서버 연결 안내

무료 호스팅(Render)이 잠들었다 깨어나는 동안의 안내. 게임 안 패널은 `client/src/data/storyText.ts`(`UI_TEXT`)에서, 깨우기 화면(`client/public/wake.html`)은 게임 코드 없이 혼자 도는 페이지라 같은 문구를 직접 적는다. 바꾸면 둘 다 고친다.

| 상황 | 화면 | 제목 | 본문 |
|---|---|---|---|
| 처음 접속을 2.5초 넘게 기다림 | 로비 자리 패널 (로고) | 서버를 깨우는 중… | 무료 서버는 15분 동안 아무도 접속하지 않으면 잠들어요. 깨어나는 데 1분쯤 걸릴 수 있어요. 이 화면을 그대로 두면 자동으로 연결돼요. |
| 연결이 끊긴 뒤 2.5초 넘게 못 붙음 | 화면 가운데 패널 | 서버에 다시 연결하는 중… | (같음) |
| 잠든 서버에 페이지를 다시 엶 | 깨우기 화면 (`wake.html`) | 서버를 깨우는 중… | (같음) |
| 마지막 방으로 돌아가는데 옛 연결이 남아 2.5초 넘게 못 들어감 (M12, 터치 · 설치 앱) | 화면 가운데 패널 | 서버에 다시 연결하는 중… | (같음) |
| 연결이 끊김 (로비 · 판) | 화면 위 알림 (2.5초) | 연결이 끊겼습니다. 다시 연결하는 중… | — |

- 기다린 시간은 `{n}초째 기다리는 중`으로 센다
- 링크 · 재연결로 들어가려던 방이 없을 때(서버가 잠들었다 깨어나면 방이 사라진다) 로비 오류 뒤에 붙는 문구: "서버가 잠들었다 깨어나거나 다시 시작하면 방이 사라져요. 새 방을 만들어 링크를 다시 보내 주세요." (직접 입력한 코드가 틀린 경우에는 붙이지 않는다)
- 깨우기 화면 추가 문구: 인터넷이 끊겼을 때 "인터넷 연결이 끊겨 있어요. 와이파이나 데이터를 확인해 주세요.", 90초가 넘으면 "생각보다 오래 걸리고 있어요. 아래 버튼으로 다시 시도하거나, 계속 안 되면 개발자에게 알려 주세요." + **다시 시도** 버튼

## 5. 터치 조작 문구 (M11)

## 6. 입력 방식별 문구 · 터치 안내 · 앱 생명주기 (M12)

키 이름이 박힌 문구는 입력 방식(`InputMode`: 키보드 · 마우스 / 터치)마다 따로 둔다. PC 문구는 그대로이고, 터치 모드(`device.touch`)에서만 아래 터치 문구를 쓴다. 고르는 함수: `roleAbility(role, mode)` · `controlsText(team, mode)`.

| 판 | 수감 중 안내 | 수감 중 — 동료가 감옥 문 앞에서 E로 구조하면 풀려난다 | 수감 중 — 동료가 감옥 문 앞에서 구조 버튼을 누르고 있으면 풀려난다 | `HUD_TEXT.imprisonedHint` · `imprisonedHintTouch` |
| 판 | 안내 · 점수판 닫기 | 아무 키나 누르면 닫힘 · Tab으로 다시 보기 | 화면을 누르면 닫힘 · 점수판 버튼으로 다시 보기 | `HUD_TEXT.closeHint` · `closeHintTouch` |

- 터치 모드에서 수감 안내는 판 맨 아래 가장자리 띠 안 안내 줄에(PC는 아래 띠 가운데 행동 칸 자리), 닫기 안내는 점수판 맨 아래 줄에 나온다(터치 점수판은 점수판 버튼으로 켜고, 열려 있으면 화면 어디를 눌러도 닫힌다). 첫 판 조작 안내 오버레이(PC)는 터치 모드에서 만들지 않는다
- 터치 점수판의 조작 안내는 `CONTROLS_TOUCH`(아래 표)다. 낮은 화면에서 점수판이 다 들어가지 않으면 조작 안내 줄을 빼고 상태 표 · 닫기 안내만 보인다

조작 안내(점수판 화면 · 첫 판 안내, `CONTROLS` · `CONTROLS_TOUCH`):

| 팀 | 키보드 · 마우스 | 터치 |
|---|---|---|
| 생존자 | WASD  이동 (바라보는 방향 = 이동 방향) | 왼쪽 스틱  이동 (바라보는 방향 = 이동 방향) |
| 생존자 | Space  고유 능력 | 능력 버튼  고유 능력 |
| 생존자 | E (누르고 있기)  감옥 문 앞에서 구조 | 구조 버튼 (누르고 있기)  감옥 문 앞에서 구조 |
| 생존자 | Tab (누르고 있기)  점수판 · 상태 | 점수판 버튼  점수판 · 상태 |
| 생존자 | 거점 A · B를 점령하고, 두 사람이 함께 탈출구에 3초 서 있으면 문이 열린다 | (같음) |
| 괴물 | WASD  이동 · 마우스  조준 | 왼쪽 스틱  이동 · 오른쪽 스틱  조준 |
| 괴물 | 좌클릭  공격 · 우클릭  시야 모드 (탐색 ↔ 추적) | 오른쪽 스틱을 놓으면  공격 (가운데로 되돌리면 취소) |
| 괴물 | Shift  돌진 · Q  포효 | 돌진 버튼 (끌어서 방향)  돌진 · 포효 · 시야 버튼 |
| 괴물 | Tab (누르고 있기)  점수판 · 상태 | 점수판 버튼  점수판 · 상태 |
| 괴물 | 생존자를 두 번 때리면 감옥으로. 두 명을 죽이거나 셋 모두 가두면 승리 | (같음) |

### 첫 실행 터치 안내 (`TOUCH_TEXT`)

이 기기에서 처음이면 판 직전(준비 후 대기 · 빠른 매칭 대기 · 연습 시작 전)에 보이고, 그 판의 처음 10초 동안 스틱 · 버튼 자리를 반투명 도형으로 보인다. 로비 설정에서 다시 볼 수 있다.

| 자리 | 문구 | 코드 |
|---|---|---|
| 제목 | 터치 조작 | `tutorialTitle` |
| 생존자 본문 | 왼쪽 아래를 누르고 끌면 이동 — 누른 자리가 스틱 가운데 / 오른쪽 아래 능력 버튼 · 감옥 문 앞에서는 구조 버튼을 누르고 있기 / 오른쪽 위 점수판 버튼으로 팀 상태 보기 | `tutorialSurvivor` |
| 괴물 본문 | 왼쪽 아래를 누르고 끌면 이동 — 누른 자리가 스틱 가운데 / 오른쪽 조준 스틱을 끌어 조준하고, 놓으면 공격 · 가운데로 되돌리면 취소 / 돌진 버튼은 끌어서 방향을 정하고, 짧게 탭하면 지금 방향으로 / 포효 · 시야 버튼은 탭 · 오른쪽 위 점수판 버튼 | `tutorialMonster` |
| 닫기 버튼 | 알겠어요 | `tutorialOk` |
| 판 중 이동 영역 표시 | 여기를 누르고 끌어 이동 | `hintMove` |

- 판 중 위치 표시(처음 10초)는 이동 영역에만 이름표를 단다. 스틱 · 버튼은 빛 고리로 자리를 보이고, 이름은 버튼 이름표(5절)가 이미 보인다
