# 피드백 검토와 반영 결정

2026.10.07 수업 피드백(손글씨 메모)과 팀 내 결정을 v2 설계에 어떻게 반영했는지 정리한다. 손글씨를 옮겨 적은 것이라 판독이 불확실한 항목은 따로 표시했다.

## 전제가 바뀐 점

| 바뀐 점 | 결정 |
|---|---|
| 괴물을 사람이 조작한다 | AI 괴물 시절의 규칙(0.2초 감지, 0.5초 발각, 실루엣, 흔적 마커, 해제 시간)을 **삭제**한다. 사람의 눈과 반응 속도가 그 역할을 한다 |
| 플랫폼을 웹으로 바꾼다 | 판정은 전용 서버가 한다. 방장 PC가 호스트가 아니므로 **"괴물은 호스트 불가" 규칙도 삭제**한다. 4명 모두 같은 지연 조건이다 |
| 1인 개발 + 팀원은 테스트 | 시스템 수를 줄인다. 아이템 상자 시스템은 생존자 고유 능력으로 대체한다 |

## 피드백 항목별 결정

| # | 메모 (판독) | 해석 | 결정 |
|---|---|---|---|
| 1 | 괴물 시야: 좁고 길게 / 넓고 얕게 → 시야를 플레이어가 선택할 수 있게 | 괴물 시야 형태를 상황에 맞게 고르게 하자 | **채택.** 우클릭으로 *탐색 모드*(넓고 짧게)와 *추적 모드*(좁고 길게)를 전환한다. 생존자도 부채꼴 모양으로 괴물의 의도를 읽을 수 있다 |
| 2 | 거점 점령하면 노티 (괴물에게도) | 점령 결과를 양쪽에 알리자 | **채택.** 점령 시작은 괴물에게, 점령 완료는 양쪽 모두에게 알린다. 구조 완료도 괴물에게 알린다 |
| 3 | 플레이어가 1명? | 생존자가 혼자 남으면 어떻게 되나 | **규칙 정의.** 두 명이 탈출해 승리가 확정되면 남은 한 명에게 "최후의 30초"가 주어진다. 두 명이 죽으면 즉시 괴물 승리 |
| 4 | 감옥에 2명 들어간다면? | 동시 수감 처리 | **규칙 정의.** 구조 한 번에 감옥 안 전원이 풀려난다. 세 명이 동시에 갇히면 괴물 승리 |
| 5 | 플레이어가 2대 맞으면 죽음 | 피격 규칙을 더 단순하고 짧게 | **부분 채택.** 2회 피격 → 수감은 유지(구조 협동이 핵심이라). 대신 수감 가능 횟수를 3회 → **2회**로 줄여 세 번째 체포에서 사망한다 |
| 6 | 생존자끼리 모이면? → 한 명이라도 더 살려보자는 느낌이 나올 수도 | 모이는 것에 보상을 주자 | **채택.** 두 명이 함께 점령하면 1.5배 빠르다. 탈출구는 두 명이 함께 있어야 열린다. 결과 화면을 탈출 인원별 등급으로 보여 준다 |
| 7 | 탈출구를 2개로 해보는 건? (최후의 탈출구는 여러 개로, 2명 이상으로 열리게) | 탈출구 길목 지키기를 막고 협동을 요구하자 | **채택.** 탈출구 2곳(북·남). 두 거점을 모두 점령하면 활성화되고, **생존자 두 명이 함께 3초** 머물러야 열린다. 한 번 열리면 계속 열려 있다 |
| 8 | 데바데에서 터널링, 캠핑? | 갓 구출된 사람을 바로 다시 쫓는 것(터널링), 감옥 앞 지키기(캠핑) 대책 | **채택.** 캠핑: 감옥 반경 감속 유지 + 구조 완료 알림. 터널링: 풀려난 생존자는 **4초 보호**(피격 무효) |
| 9 | (판독 불확실) "○○ 얻으면 생존 / 괴물에게 보이게" | 무엇인가를 얻으면 위험(괴물에게 위치 노출)과 이득을 같이 주는 장치로 추정 | **보류 — 확인 필요.** 비슷한 의도는 괴물의 *포효*(생존자 위치 노출)와 스카우트의 *탐지*로 일부 반영했다. 원래 뜻을 확인하면 추가한다 |
| 10 | 로스트 바이킹(블리자드) 참고해 보기 (스토리라인) | 능력이 서로 다른 세 캐릭터가 협력하는 구조 | **채택.** 생존자 3명에게 고유 능력을 준다 — **러너**(질주), **가드**(밀쳐서 기절), **스카우트**(괴물 위치 탐지). 스토리에도 세 사람의 개성을 넣는다 |
| 11 | 거점을 3개나 점령 (너무 많다) | 판이 길고 반복적이다 | **채택.** 거점 **2개**로 줄인다. 비밀번호도 두 조각 |
| 12 | 괴물이 플레이어니까 괴물의 플레이에 특색이 있어야 하지 않나 (능력 부여) | 괴물도 조작할 거리가 필요하다 | **채택.** 시야 모드 전환 + **돌진**(짧은 거리 순간 이동) + **포효**(주변 생존자 위치를 잠깐 드러내지만 괴물 위치도 알려짐) |

## 추가로 넣은 것 (피드백 외)

| 항목 | 이유 |
|---|---|
| 판 제한 시간 12분 | 생존자가 숨기만 해서 판이 끝나지 않는 상황을 막는다. 시간이 다 되면 탈출하지 못한 생존자는 사망 처리 |
| 괴물 화면에서 생존자는 모두 같은 흰색 | 사람 괴물에게 바로 보이게 바꾸면서도 "저게 누구지?" 하는 미끼 심리전을 남긴다. 능력을 쓰면 정체가 드러난다 |
| 서버가 보이는 것만 보낸다 | 각 클라이언트에 볼 수 있는 대상만 전송해 안개를 우회할 수 없게 한다. v1에서 "알려진 한계"로 남겼던 문제를 웹판에서는 해결한다 |
