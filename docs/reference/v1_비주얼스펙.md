# DECOY 비주얼 스펙

화면에 무엇이 어떻게 그려지는지에 대한 구현 기준 문서.

> **이 문서의 위치**
레퍼런스 이미지는 "이런 느낌"을 합의하는 용도이고, 실제 구현은 이 문서의 수치를 따른다. 이미지와 문서가 어긋나면 문서가 우선한다.
>
> 아래 수치는 초기값이다. 3~4주차 구현 중에 눈으로 확인하고 조정하되, **조정한 값은 반드시 이 문서에 반영한다.** 각자 코드에만 넣어두면 세 사람의 기준이 갈라진다.
>
> **2026.09.20 보완** — 개정 과정에서 빠졌던 설명(시야 경계 처리 이유, 벽 차폐, 기억 상태, 항상 표시 배지, 성능 대응)을 복원했다.
>
> **2026.09.17 개정** — 괴물이 플레이어 조작 1명으로 바뀌어, 화면이 **생존자 화면**과 **괴물 화면** 두 종류로 나뉘었다. 기존 레퍼런스 이미지는 괴물 3마리 기준이므로 괴물 수와 범례는 이 문서를 따른다.

## 1. 좌표계와 단위

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 기준 단위 | 1 타일 | 모든 거리는 타일 단위로 표기 |
| 1 타일 실제 크기 | 1 Unity unit | 3주차에 확정 |
| 시점 | 정직교 탑다운 | 원근 없음 |
| 카메라 | 맵 전체 고정 | 스크롤·줌 없음, 두 역할 공통 |

**카메라를 고정으로 두는 이유**

생존자 3명이 흩어져 움직이는데 카메라가 따라다니면 각자 다른 구역을 보게 되어 시야 공유의 의미가 약해진다. 괴물 화면도 같은 카메라를 써서 맵 구조 파악 조건을 동일하게 맞춘다. 보이지 않는 곳은 역할별 안개로 가린다.

## 3. 시야 시스템

### 3.1 생존자 시야

| 항목 | 값 |
| --- | --- |
| 형태 | 원형 360도 |
| 반지름 | 6 타일 |
| 경계 처리 | 바깥 1.2 타일에 걸쳐 부드럽게 감쇠 |
| 벽 차단 | 적용. 벽 뒤는 원 안이어도 보이지 않음 |
| 갱신 주기 | 0.1초 |

경계를 딱 자르지 않고 흐리는 이유는 생존자가 움직일 때 원 테두리가 계단처럼 튀는 것을 막기 위해서다.

### 3.2 괴물 부채꼴 시야

| 항목 | 값 |
| --- | --- |
| 형태 | 부채꼴 |
| 각도 | 70도 |
| 사거리 | 8 타일 |
| 방향 | 괴물 플레이어의 마우스 조준 방향 |
| 경계 처리 | 하드 컷 (판정 범위와 정확히 일치) |
| 벽 차단 | 적용 |

**생존자 시야와 달리 하드 컷으로 처리한다.** 이 부채꼴은 연출이 아니라 판정 범위 그 자체다. **생존자 화면의 부채꼴과 괴물 화면의 시야 경계는 같은 메시를 쓴다.** 둘이 어긋나면 "안 보였는데 잡혔다"는 억울함이 생긴다.

### 3.3 괴물 근접 원형 시야

| 항목 | 값 |
| --- | --- |
| 형태 | 원형 360도 |
| 반지름 | 1.5 타일 |
| 경계 처리 | 바깥 0.3 타일 감쇠 |
| 벽 차단 | 적용 |
| 표시 대상 | 괴물 화면에만 |

생존자 화면에는 그리지 않는다. 생존자에게 보이는 괴물 시야는 부채꼴뿐이다.

### 3.4 시야 합성

**생존자 화면** — 생존자 3명의 시야를 합집합으로 처리한다. 겹치는 구간에서 밝기가 누적되지 않도록 한다.

**괴물 화면** — 부채꼴과 근접 원을 합집합으로 처리한다. 생존자 시야는 일절 포함하지 않는다.

### 3.5 표시 상태

| 상태 | 화면 |
| --- | --- |
| 관측 중 | 바닥, 벽, 장애물, 상대 캐릭터, 아이템 표시 |
| 미관측 | 완전한 검정 |
| 항상 표시 | 거점 3개, 감옥, 탈출구의 위치 배지 |

**기억 상태는 없다.** 한 번 지나간 구역도 시야에서 벗어나면 다시 검정으로 돌아간다.

**항상 표시되는 배지**는 위치만 알려준다. 그 주변 지형이나 상대 캐릭터는 보이지 않는다. 미관측 영역에 놓인 배지는 알파 45%로 낮춰 관측 중인 것과 구분한다.

## 4. 역할별 화면

같은 판을 하더라도 역할에 따라 화면에 그리는 것이 다르다. 역할 값은 게임 시작 시 한 번 받고, 이후 모든 렌더링을 분기한다.

### 4.1 생존자 화면에 보이는 것

| 대상 | 조건 |
| --- | --- |
| 자신과 팀원 2명 | 항상 |
| 생존자 시야 원 3개 | 항상 |
| 괴물 아이콘 | 생존자 시야 합집합 안에 있을 때 |
| 괴물 부채꼴 (상태 색) | 괴물이 생존자 시야 합집합 안에 있을 때 |
| 괴물 공격 준비 모션 | 괴물이 보일 때 |
| 아이템 상자 | 시야 안 |

### 4.2 괴물 화면에 보이는 것

| 대상 | 조건 |
| --- | --- |
| 괴물 자신 | 항상 |
| 자기 부채꼴 | 항상. 색은 가장 높은 감지 단계를 따름 |
| 자기 근접 원 | 항상 (알파 10%) |
| 생존자 | 아래 4.3 규칙 |
| 생존자 시야 원 | **표시하지 않음** |
| 흔적 마커 | 발각 생존자가 사라진 위치, 3초 |
| 아이템 상자 | 표시하지 않음 (괴물은 사용 불가) |

### 4.3 괴물 화면의 생존자 표시 규칙

생존자별 감지 단계는 호스트가 판정해 동기화한다. 괴물 화면은 그 값에 따라 그린다.

| 생존자 위치 · 단계 | 표시 |
| --- | --- |
| 부채꼴 안, 노출 0.2초 미만 | 표시 안 함 |
| 부채꼴 안, 감지 (0.2초 이상) | **실루엣** — 괴물 색 `#EF4444` 단색, 알파 35%, 크기 1.2배, 위치 흔들림 ±0.2타일 |
| 부채꼴 안, 발각 (0.5초 이상) | **선명** — 생존자 고유색, 알파 100% |
| 근접 원 안 | 즉시 선명 |
| 발각 후 시야 이탈 | 흔적 마커로 전환 |

실루엣은 **누구인지 알 수 없도록** 고유색을 쓰지 않고, 위치도 약간 흔들어 정확한 좌표를 주지 않는다.

### 4.4 흔적 마커

| 항목 | 값 |
| --- | --- |
| 형태 | 점선 원 + 중앙 점 |
| 크기 | 지름 0.8 타일 |
| 유지 시간 | 3초 |
| 소멸 | 마지막 1초 동안 알파 100% → 0% |

## 5. 렌더 레이어 순서

아래에서 위로 그린다.

### 5.1 생존자 화면

```
1. 배경
2. 바닥
3. 장애물 · 기둥
4. 벽 외곽선
5. 거점 영역 (바닥 위 발광)
6. 생존자 시야 원 (가산 혼합)
7. 괴물 시야 부채꼴 (가산 혼합)
8. 안개 마스크 (생존자 시야 합집합)   ← 6, 7번을 덮는다
9. 아이템 상자
10. 괴물 아이콘 · 공격 준비 모션
11. 생존자 아이콘
12. 항상 표시 배지
13. HUD
```

### 5.2 괴물 화면

```
1. 배경
2. 바닥
3. 장애물 · 기둥
4. 벽 외곽선
5. 거점 영역
6. 괴물 근접 원
7. 괴물 부채꼴 (가산 혼합)
8. 안개 마스크 (부채꼴 + 근접 원)
9. 흔적 마커
10. 생존자 실루엣 · 선명 표시
11. 괴물 아이콘
12. 항상 표시 배지 (점령 알림 깜빡임 포함)
13. HUD
```

**8번 위치가 중요하다.** 안개는 시야보다 위에 있어야 한다.

**9번 이상은 안개 위에 그리지만, 조건을 만족하지 않는 대상은 아예 그리지 않는다.** 안개 위 레이어라고 무조건 보여서는 안 된다. 특히 괴물 화면에서 생존자 오브젝트는 렌더러 자체를 끄는 방식으로 처리한다. 알파만 0으로 두면 디버그 중 실수로 노출되기 쉽다.

## 6. 아이콘 규격

| 대상 | 형태 | 크기 |
| --- | --- | --- |
| 생존자 | 채워진 원 + 방향 노치 | 지름 0.6 타일 |
| 괴물 | 후드 실루엣 + 조준 방향 노치 | 높이 0.7 타일 |
| 거점 | 마름모 외곽선 + 숫자 | 폭 0.8 타일 |
| 감옥 | 자물쇠 + 사각 테두리 | 2×2 타일 |
| 아이템 상자 | 상자 실루엣 | 0.5 타일 |
| 탈출구 | 달리는 사람 + 문 | 1.5 타일 |
| 흔적 마커 | 점선 원 + 중앙 점 | 0.8 타일 |
| 괴물 스폰 지점 | 표시하지 않음 | — |

모든 아이콘은 단색 채움 또는 단색 외곽선. 그라디언트와 그림자를 쓰지 않는다.

## 7. HUD 배치

### 7.1 생존자 HUD

| 위치 | 요소 |
| --- | --- |
| 상단 중앙 | 거점 3개 게이지 바 (가로 배열) |
| 좌측 상단 | 생존자 3명 상태 카드 (체력, 상태, 수감 횟수, 아이템 슬롯) |
| 좌측 상단 하단 | **발각 경고** — 내가 발각 상태일 때 빨간 테두리 배너 |
| 우측 상단 | 미니맵 |
| 중앙 | 게임 화면 |

기존 "괴물 3마리 상태 아이콘" 영역은 삭제하고 발각 경고로 대체한다.

### 7.2 괴물 HUD

| 위치 | 요소 |
| --- | --- |
| 상단 중앙 | 거점 3개 게이지 바. **점령 중인 거점은 배지가 0.5초 간격으로 깜빡임** |
| 좌측 상단 | 생존자 3명 상태 (정상 / 부상 / 수감 / 사망, 수감 횟수). 위치는 표시하지 않음 |
| 하단 중앙 | 공격 쿨타임 원형 게이지, 스턴 남은 시간 |
| 하단 중앙 위 | 감옥 캠핑 경고 — 반경 안 3초부터 주황 배너, 5초에 감속 적용 표시 |
| 우측 상단 | 미니맵 |
| 중앙 | 게임 화면 |

### 7.3 미니맵 규칙

**메인 화면과 동일한 역할별 안개 규칙을 적용한다.**

| 역할 | 미니맵 표시 |
| --- | --- |
| 생존자 | 생존자 시야 합집합, 관측 중인 괴물, 팀원 위치 |
| 괴물 | 괴물 시야 범위, 선명하게 보이는 생존자, 흔적 마커, 점령 중 거점 |
| 공통 | 맵 외곽선, 거점·감옥·탈출구 위치 |

미니맵에서 메인 화면보다 많은 정보가 보이면 안개가 무력화된다.

## 8. 상태 전환 연출

| 전환 | 연출 | 시간 | 화면 |
| --- | --- | --- | --- |
| 평상시 → 감지 | 부채꼴 색상 보간 | 0.15초 | 양쪽 |
| 감지 → 발각 | 색상 보간 + 짧은 확장 | 0.1초 | 양쪽 |
| 발각 → 평상시 | 색상 보간 | 0.4초 | 양쪽 |
| 실루엣 → 선명 | 알파·색상 보간 | 0.1초 | 괴물 |
| 괴물 공격 준비 | 괴물 앞 타격 범위 반투명 표시 | 0.4초 | 양쪽 |
| 거점 점령 진행 | 원형 게이지 링이 채워짐 | 실시간 | 양쪽 |
| 점령 시작 알림 | 거점 배지 깜빡임 + 짧은 효과음 | 점령 중 지속 | 괴물 |
| 생존자 피격 | 화면 가장자리 붉은 플래시 | 0.2초 | 피격 생존자 |
| 수감 | 화면이 감옥으로 전환 | 0.5초 페이드 | 수감 생존자 |
| 스턴 | 화면 채도 감소 + 남은 시간 표시 | 스턴 지속 | 괴물 |
| 탈출구 개방 | 탈출구 배지 발광 + 배너 | 1초 | 양쪽 |

발각 전환을 빠르게, 해제를 느리게 하는 것은 위험을 즉시 알리되 안심은 천천히 하게 만들기 위해서다.

**공격 준비 범위 표시**는 회피 플레이의 핵심이다. 생존자가 이 표시를 보고 범위 밖으로 나갈 수 있어야 한다.

| 목표 프레임 | 60 FPS |
| 시야 갱신 | 0.1초 간격. 매 프레임 계산하지 않음 |
| 시야 계산 위치 | 각 클라이언트 로컬, 역할에 해당하는 시야만 계산 |
| 네트워크 전송 | 4명 위치, 괴물 조준 방향, 생존자별 감지 단계. 시야 데이터는 전송하지 않음 |
| 4인 테스트 환경 | ParrelSync 복제본 3개. 복제본은 그래픽 품질 최저로 둔다 |

시야 계산이 프레임을 떨어뜨리면 갱신 주기를 0.15초까지 늘리고, 그래도 부족하면 계산 해상도를 낮춘다. 단 **괴물 부채꼴은 판정과 일치해야 하므로 괴물 화면의 부채꼴 갱신 주기는 늘리지 않는다.**

## 10. 검수 체크리스트

3~4주차 시야 구현 후 아래를 확인한다.

### 10.1 생존자 화면

- [ ]  벽 뒤가 보이지 않는가
- [ ]  시야에서 벗어난 구역이 다시 검게 돌아가는가
- [ ]  세 시야가 겹칠 때 과도하게 밝아지지 않는가
- [ ]  아무도 보지 않는 괴물이 화면과 미니맵 모두에 표시되지 않는가
- [ ]  괴물 공격 준비 범위가 보이는가
- [ ]  발각 시 경고 배너가 뜨는가

### 10.2 괴물 화면

- [ ]  부채꼴과 근접 원 밖이 검게 가려지는가
- [ ]  생존자 시야 원이 보이지 않는가
- [ ]  노출 0.2초 미만 생존자가 보이지 않는가
- [ ]  감지 단계 실루엣이 누구인지 구분되지 않는가
- [ ]  흔적 마커가 3초 후 사라지는가
- [ ]  점령 중 거점 배지가 깜빡이는가
- [ ]  미니맵에 볼 수 없는 생존자가 표시되지 않는가

### 10.3 공통

- [ ]  생존자 화면의 부채꼴과 괴물 화면의 시야 경계가 일치하는가
- [ ]  부채꼴 경계와 실제 판정 범위가 일치하는가
- [ ]  거점·감옥·탈출구 배지가 항상 보이는가
- [ ]  미관측 영역의 배지가 관측 중인 것과 구분되는가
- [ ]  4인 테스트 환경에서 60 FPS를 유지하는가

## 11. 레퍼런스 이미지 수정 사항

기존 이미지는 괴물 3마리 기준으로 제작되었다. 재제작 시 다음을 반영한다.

- 괴물 3마리 → 1마리
- 범례 "AI 괴물" → "괴물 (플레이어)"
- 상태 표시 예시에 괴물 화면 실루엣·선명 표시 추가
- 괴물 화면 예시 이미지 별도 제작 (부채꼴만 밝고 나머지 검정, 상단 점령 알림)
