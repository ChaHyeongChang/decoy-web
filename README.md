# DECOY v2 (웹판)

<img src="docs/images/logo_decoy.png" alt="DECOY 로고" width="120" align="right" />

생존자 3명과 괴물 1명이 브라우저로 접속해 겨루는 온라인 비대칭 탈출 게임이다. 설치 없이 링크 하나로 4명이 들어온다. PC와 휴대폰(가로 화면, 터치)이 같은 방에서 함께 하고, 안드로이드 앱(PWA를 감싼 TWA)으로 구글 플레이에 올릴 준비가 되어 있다.

- 생존자는 흩어져 거점 A · B를 점령하고, 두 명이 함께 탈출구를 열어 빠져나간다. 괴물에게는 모든 생존자가 **흰색**으로 보여서, 누가 누구인지 숨기며 미끼가 될 수 있다
- 괴물은 마우스로 시야와 공격 방향을 조준해 생존자를 쫓는다. 두 번 맞은 생존자는 감옥으로 간다
- 서버가 모든 판정을 하고, 플레이어마다 **볼 수 있는 것만** 보낸다(시야 밖 상대의 좌표는 아예 오지 않는다)

TypeScript · Phaser 3 · Node `ws` 권한 서버. 그래픽은 코드로 그리고(질감 · 빛 · 안개, 품질 높음 · 중간 · 낮음), 효과음은 WebAudio로 합성한다.

## 화면

| 휴대폰 가로 — 생존자(러너), 화면 밖 화살표 · 지도 | PC — 괴물, 생존자는 모두 흰색으로 보인다 |
|---|---|
| ![휴대폰 생존자 화면](artifacts/camera/final/phone-800x360/survivor-arrows.png) | ![PC 괴물 화면](artifacts/camera/final/pc-1920x1080/monster-arrows.png) |

![휴대폰: 걷기 → 수감 → 팀원 화면 보기(관전)](artifacts/camera/final/phone-800x360/walk-spectate.gif)

실제 게임을 헤드리스 크롬으로 찍은 그림이다(`tests/camera/`). 화면은 내 캐릭터 둘레 16 × 10.7타일을 따라가고, 화면 밖에 있는 팀원 · 거점 · 탈출구는 가장자리 화살표로 가리킨다(괴물 화면은 점령 중인 거점 · 포효로 드러난 자리만).

## 실행

Node 22 이상과 npm이 필요하다 (런타임은 Node 20 이상이면 되지만, 빌드 · 테스트 도구가 Node 22를 요구한다).

```bash
npm ci
npm run build
npm start            # http://localhost:8080
```

- **한 컴퓨터에서 시험**: 브라우저 탭 4개로 같은 방에 들어간다 (탭마다 다른 자리)
- **같은 와이파이**: `npm start` 한 컴퓨터의 IP로 `http://<IP>:8080/?room=방코드` (자세히: [docs/DEPLOY.md](docs/DEPLOY.md))
- **인터넷**: Render 무료 플랜(싱가포르, `render.yaml` — 태블릿 브라우저만으로 배포)을 쓰거나, Dockerfile로 한국 · 일본 리전 서비스에 배포한다 → [docs/DEPLOY.md](docs/DEPLOY.md). 무료 서버가 잠들어 있으면 깨어나는 동안 "서버를 깨우는 중…" 안내가 뜬다
- **개발 모드**: `npm run dev` (서버 + Vite 핫 리로드, http://localhost:5173)

### 첫 화면에서 시작하는 법

| 버튼 | 뜻 |
|---|---|
| 빠른 매칭 | 모르는 사람과 자동으로. 20초 안에 4명이 모이지 않으면 빈자리를 봇으로 채워 시작한다(서버가 동시에 돌릴 수 있는 봇 방 수 안에서) |
| 봇과 연습 | 역할을 고르면 바로 봇 셋과 한 판. 기기 안에서 판정해 서버가 필요 없다(오프라인 · 서버가 잠든 동안에도) |
| 방 만들기 · 코드 입장 | 친구 방. 4글자 방 코드나 링크(`/?room=ABCD`)로 부른다 |

### 휴대폰 · 안드로이드

- **휴대폰 브라우저**: 같은 주소를 가로로 들고 연다. 왼쪽 엄지로 이동 스틱, 오른쪽 엄지로 버튼(괴물은 조준 스틱). 첫 판 전에 터치 조작 안내가 한 번 뜬다
- **설치(PWA)**: 크롬 메뉴의 '홈 화면에 추가' 또는 '앱 설치' → 주소창 없이 가로 · 전체 화면으로 열린다. 한 번 온라인으로 연 뒤에는 오프라인에서도 앱이 열리고 봇과 연습을 할 수 있다
- **구글 플레이 앱**: PWABuilder로 만든 TWA 패키지를 올린다. 계정 · 서명 키 · 결제가 필요한 일은 사람이 [docs/PLAY_STORE_GUIDE.md](docs/PLAY_STORE_GUIDE.md)를 따라 한다. 스토어에 옮겨 적을 글 · 답은 [docs/STORE_LISTING.md](docs/STORE_LISTING.md), 그림은 `artifacts/store/`
- **개인정보 처리방침**: `/privacy` (첫 화면 아래 링크). 문의처는 배포 환경 변수 `PRIVACY_CONTACT`

### 설정

설정은 PC · 휴대폰 모두 같은 화면 하나다. **첫 화면 로고 아래 '설정'**, 방 화면 · 빠른 매칭 대기의 명령 줄 '설정'에서 연다. 판 중에는 **PC 위 띠 왼쪽 '설정' 단추(또는 Esc)**, **휴대폰 오른쪽 위 '설정' 버튼**으로 연다 — 온라인 판이라 판은 멈추지 않고, 판 중에는 그래픽 · 화면 · 소리 탭만 보인다.

| 탭 | 항목 |
|---|---|
| 그래픽 | 품질(자동 · 높음 · 중간 · 낮음) · 프레임 제한(자동 · 60 · 120) · 캐릭터 스타일(새 캐릭터 · 기존, 기본 새 캐릭터) |
| 화면 | UI 크기(보통 · 크게 · 아주 크게) · 화면 흔들림 줄이기 · 번쩍임 줄이기 · FPS · 핑 표시 |
| 소리 | 전체 · 효과음 · UI 음량 · 음소거 |
| 조작 | 휴대폰: 조이스틱 크기 · 투명도 · 진동 · **조작 배치 편집**(로비에서만) · 터치 안내 다시 보기. PC: 키보드 · 마우스 조작. 둘 다 화면 밖 화살표 설명 |

- 모든 설정은 기기에 저장된다(처리방침의 '기기에 저장하는 것'). 줄마다 '기본값', 아래에 '모두 기본값으로'(두 번 눌러 확인)
- **조작 배치 편집**(휴대폰 · 태블릿): 이동 스틱 · 조준 스틱 · 모든 터치 버튼을 끌어 옮기고 크기를 바꾼다. 생존자 · 괴물 배치를 따로 저장하고, 왼손잡이용 좌우 반전이 있다. 화면 가장자리 · 노치 밖, 버튼끼리, 판 HUD와 겹치는 자리에는 놓을 수 없다. 화면 비율로 저장해 다른 휴대폰 · 태블릿 · 화면 회전 뒤에도 자리가 유지된다
- 주소 옵션(`?quality` · `?fpsLimit` · `?chars`)이 있으면 그 접속에는 주소 값이 우선하고, 설정 화면의 그 줄에 그렇다고 표시한다

### 주소 옵션

| 옵션 | 뜻 |
|---|---|
| `?room=ABCD` | 그 방으로 바로 들어간다 (로비의 "링크 복사") |
| `?bots=1` | 개발 서버(`npm run dev` · `--dev` · `DECOY_DEV_BOTS=1`) 전용: 방을 만들 때 붙이면, 시작할 때 빈 역할을 순찰 봇이 채운다 (혼자 시험). 배포 서버는 무시하고 일반 방을 만든다 |
| `?practice=1` | 바로 봇과 연습 역할 고르기 (서버 없이, 앱 셸 캐시에서) |
| `?quality=low` | 그래픽 품질 낮음 (high · medium · low). 설정 화면 '품질'보다 우선하고(이 주소로 연 동안만, 저장하지 않음) 설정 화면에 그 사실을 보인다 |
| `?scale=0.5` | 렌더 해상도 배율 (0.25~1, 화면 크기 × 기기 픽셀 배율로 정한 해상도에 곱한다) |
| `?debug=1` | 성능 · 네트워크 오버레이: FPS · 목표 · 화면 주사율 · 프레임 제한, 프레임 시간(평균 · p95), 핑, 서버 틱, 예측 오차, 그리기 호출 수, 품질 단계, DPR. 배포 빌드에서도 켜지고, 휴대폰에서는 접힌 칩을 눌러 펼친다 ([docs/PERF.md](docs/PERF.md) 2장) |
| `?chars=classic` | 캐릭터 스타일 (new · classic). 설정 화면 '캐릭터 스타일'(처음에는 새 캐릭터)보다 우선하고, 이 주소로 연 동안만 쓰고 저장하지 않는다 |
| `?fpsLimit=60` | 프레임 제한 (auto · 60 · 120). 설정 화면 '프레임 제한'(처음에는 자동)보다 우선하고, 이 주소로 연 동안만 쓰고 저장하지 않는다 |
| `?lag=200` | 인위적 지연 (왕복 ms, 시험용) |
| `?renderer=canvas` | Canvas 렌더러 강제 (기본은 WebGL) |

## 규칙 요약

- **한 판 12분.** 생존자 셋은 중앙 감옥에서, 괴물은 맵 구석에서 시작한다. 괴물은 처음 5초 동안 움직일 수 없다
- **거점 A · B**: 자유 생존자가 안에 있으면 40초에 점령(2명 이상이면 1.5배). 괴물이 안에 있으면 멈춘다(5초 넘게 지키면 풀림). 점령하면 생존자에게 비밀 메모가 뜬다
- **탈출구 북 · 남**: 두 거점을 모두 점령하면 켜진다. 생존자 두 명이 한 탈출구에 함께 3초 서 있으면 문이 열리고, 열린 문으로 걸어 나가면 탈출
- **공격**: 두 번 맞으면 감옥으로. 수감 두 번 뒤 세 번째로 잡히면 사망. 동료가 감옥 문 앞에서 E를 3초 누르면 전원 풀려나고 4초 보호
- **능력**: 러너 질주(3초 ×1.45), 가드 밀치기(2타일 안 괴물 1.5초 기절), 스카우트 탐지(4초간 괴물 위치 공유). 능력을 쓰면 1초 동안 괴물에게 역할 색이 보인다. 괴물은 돌진(4타일)과 포효(반경 10 안 생존자 위치를 잠깐 보지만 자기 위치도 드러남)
- **승패**: 두 명 이상 탈출하면 생존자 승리(남은 사람은 최후의 30초). 두 명이 죽거나 세 명이 모두 갇히면 괴물 승리. 12분이 지나면 남은 생존자는 사망
- **접속이 끊기면** 30초 안에 같은 탭(새로고침)으로 돌아오면 그대로 이어진다. 괴물이 끊기면 판 전체가 멈추고, 30초 안에 안 돌아오면 판은 무효

모든 수치는 `config/balance.json`에 있고, 규칙의 원본은 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)다.

## 테스트

```bash
npm run check          # 타입 · 린트 · 포맷
npm test               # 단위 + 봇 시나리오 (규칙 · 정보 차단 · 동기화)
npm run test:e2e       # 빌드 후 브라우저 4개 E2E 전체 (Playwright, 스크린샷은 artifacts/)
npm run test:e2e:core  # 핵심 E2E만 (@core 태그, PR CI가 돌리는 것)
npm run test:lag       # lag 100 · 200 실서버에 WebSocket 봇 4명으로 실시간 전체 판 (몇 분)
npm run verify:deploy  # Docker 이미지(없으면 빌드 결과물)를 띄워 HTTP · WebSocket · manifest · assetlinks · 처리방침 확인
npm run icons          # 로고 SVG로 PWA 아이콘 · 스토어 아이콘 PNG 만들기
npm run shots:store    # 빌드 후 실제 게임 화면으로 스토어 스크린샷 5장 · 그래픽 이미지 촬영 (artifacts/store/)
```

push · PR마다(그리고 main에 들어갈 때) GitHub Actions(`.github/workflows/ci.yml`)가 빠른 검사(`check` · `test` · `test:e2e:core`, 3분 안팎)를 돌린다. PR을 병합하기 직전에는 같은 워크플로를 그 브랜치에서 수동 실행(Actions 탭 → CI → Run workflow)해 전체 E2E(파일별 러너 시간으로 고르게 나눈 4개 작업, `scripts/e2e-shard.mjs`) · 지연 봇 판 · 배포 검증까지 돌리고, `전체 검사 결과`가 success여야 병합한다.

## 폴더

```
shared/   서버와 클라이언트가 같이 쓰는 코드 (이동 · 충돌 · 시야 · 맵 · 메시지 타입, sim/ 판정 · 방 · 정보 차단 · 봇). Phaser · Node 전용 모듈 없음
server/   권한 서버 (HTTP · WebSocket · 틱 타이머, 판정 코드는 shared/src/sim)
client/   Phaser 클라이언트 (예측 · 보간 · 렌더링 · HUD · 효과음)
config/   balance.json (수치의 원본)
tests/    unit · bots · e2e · lag · store(스토어 그림 촬영)
```
